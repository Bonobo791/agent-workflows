# Review the instructions

Review the instructions against the approved plan in this session.

Blocking (must be fixed):
- A phase that does not match the approved plan: a change the plan does not describe, or a planned change that no phase makes.
- A phase that cannot be checked: no test, or no way for the check commands to show it works.
- Missing tests for new behaviour.
- A step that needs a fact nobody checked: a function, file or flag the instructions assume without reading it in the plan or the code.
- A phase that depends on a later phase.

Minor (the owner may leave them):
- Wording and the order of sections.

Name the phase in each finding.
