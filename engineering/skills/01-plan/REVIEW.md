# Review the plan

Review the plan against the task (00-task.md) in this session. Read each file the plan names before you judge it.

Blocking (must be fixed):
- A requirement from "Done when" that the plan does not cover.
- A file in "Files to change" that does not exist and is not marked as new, or a file the change must touch that the plan leaves out.
- A design with a fallback: a default that hides a failure, a silent retry, or a second path for the same job.
- New behaviour with no test in Tests.

Minor (the owner may leave them):
- Wording, order, and headings that are clear enough.

Name the plan section in each finding. Do not ask for features the task did not request.
