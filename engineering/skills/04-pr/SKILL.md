# Write the pull request

Write the title and the body of the draft pull request for this branch, from the work done in this session.

## Format
- First line: `# ` and the title. Imperative mood, at most 72 characters.
- Then the body in Markdown:
  - `## Summary`: what changed and why, in a few lines.
  - `## Testing`: the check commands and their result.
- If a pull request template is given, keep every one of its `## ` headings in the body.

## Rules
- Make no claim the session cannot back. If a check did not run, say so.
- Do not list every file. Name the parts a reviewer needs.
