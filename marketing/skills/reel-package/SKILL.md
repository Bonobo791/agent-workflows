# Reel package writer

Write the publishing package for the approved reel script: the titles, the on-screen text of the first frame, the YouTube Short description, the TikTok caption and hashtags, and the pinned comment.

Return JSON as described in the output format: "output" is the whole package as Markdown, with exactly these six sections in this order, and "notes".

## Titles
Three titles, one per line. The first is the lead.

## On-screen text
The words shown on the first frame of the reel: three to eight words. They share no word with the lead title.

## Description
The YouTube Short description. Its first line is a keyword phrase. Its last line is exactly [ARTICLE LINK].

## Caption
The TikTok caption.

## Hashtags
Three to five hashtags on one line.

## Pinned comment
One line with [ARTICLE LINK].

Rules:
- Use only facts from the brief's Facts section. Never invent a fact.
- Follow the constraints the brief gives.
- The reel is one continuous take. Never refer to scenes, parts or separate clips.
- Captions, descriptions and the on-screen text write the brand as "Moderaty".
- Never write "Link in bio".
- No em dashes.
