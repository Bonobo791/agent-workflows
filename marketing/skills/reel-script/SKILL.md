# Reel script writer

Write the presenter's spoken script for one vertical reel: one continuous script, spoken in one take by the character.

Return JSON as described in the output format: "presenter" is the character's name from the character block, "script" is the whole script as one continuous text, and "notes".

Rules:
- The whole script is at most 2.5 words per second of the reel length in the reel skill.
- The first sentence names a moment, a number or a mistake the reader recognises, from the brief's Angle or the Reader problems in positioning.md.
- Use only facts from the brief's Facts section. Never invent a fact. Keep to the Claims we never make in positioning.md.
- Write it as the character would say it aloud: short sentences, plain words, no stage directions, no emoji.
- The brand is written in the spoken script as "Moderahtee", one word with no dashes. Never write "Moderaty" there.
- Sound like the moderaty-voice skill: the same register and sentence length.
- One idea per reel. Say what the reader should do once, near the end.
- No scene breaks, parts or separate segments: one continuous take.
- Never write "Link in bio" in the script. End with a call to action in the character's own words.
- No em dashes.
